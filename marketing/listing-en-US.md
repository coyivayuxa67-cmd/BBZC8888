# Starship Command Deck: Earth Night Departure

## Tagline

Turn your Codex workspace into a future warship bridge departing from Earth.

## Short Description

A dark DreamSkin workspace built around Earth at night, cold cyan instrumentation, deep-space panels, and clear message surfaces.

## Tags

`starship` `bridge` `deep-space` `earth` `night` `sci-fi` `dark` `dreamskin`

## Features

- 8K Earth-night background
- Dark bridge panels and cyan instrument colors
- Unified sidebar, header, message, composer, and dialog colors
- Static glass blur, borders, and radius
- Validated by DreamSkin Safe CSS

## Installation

1. Download `starship-command-deck-night-5.0.0.zip`
2. Import the ZIP with the DreamSkin client
3. Apply **Starship Command Deck: Earth Night Departure**

## Scope

This is a static DreamSkin package. It does not include Codex++ scripts, multiple backgrounds, porthole switching, meteors, alien ships, task-tree logic, or animated composer effects.

# DreamSkin Studio 投稿步骤

1. 打开 `https://dreamskin.cc/studio` 并登录。
2. 导入 `releases/starship-command-deck-night-5.0.0.zip`，或按 Studio 表单重新上传背景和 Safe CSS。
3. 检查深色外观、背景焦点、安全区和任务画面预览。
4. 在 Studio 导出正式 ZIP，确认导出文件仍通过 DreamSkin 官方校验。
5. 填写主题名称、作者、许可证、来源说明和版本说明。
6. 生成并检查真实预览图。不要使用 Codex++ 六舷窗、流星或飞船舷窗截图。
7. 选择公开发布并提交审核。
8. 审核通过后，在主题详情页检查下载、收藏和 `dreamskin://apply` 链接。
